# 公式掲示板の公開範囲 — 合意仕様 (2026-11-17)

## 3つの閲覧区分
1. **全ユーザー** `public` — ログイン不要。一般検索に公開可能。
2. **会員限定** `members` — ログイン済みの無料・有料会員。
3. **有料会員限定** `paid` — 有効な有料会員のみ。

会員は下位の公開区分も閲覧できる。公式/管理者の投稿権限は会員区分と別の運営ロールで管理する。

## 返信
初期は**有効な有料会員だけが返信可**。閲覧範囲が `public` でも返信は有料会員のみ。ロック中・返信停止中は有料会員も返信不可。無料会員の返信権限は将来の検討事項。

## 一覧と検索
- `public` はタイトル・抜粋・本文を未ログインにも公開し、SEO対象とする。
- `members` / `paid` は、未認可者に本文・抜粋・返信内容・件数・非公開タイトルを漏らさないことを初期デフォルトとする。将来「タイトルだけ公開」を導入する場合、明示的に公開可能なティーザーを別カラムに分離して審査する。
- SSR、HTML、JSON、キャッシュ、Realtime、RSS、sitemap、OGメタデータ、検索APIも同じ認可規則に従う。
- 投稿ごとの `audience` は `public|members|paid`、返信設定 `reply_policy` は `paid|disabled`、公開状態 `status` は別フィールドに分離する。
- 会員の有効性はサーバーで検証する。 `user_metadata` や本人が更新できる `bs_member_profiles.plan/is_admin` を単独の根拠にしない。

## 既存の試作との互換性
PR #300 の初期公開ページは暫定的に `visibility=public_all|public_post_members_replies` を参照している。**新仕様のDBを作成する前に** API、公開ページ、一覧のクエリを `audience` と `reply_policy` に移行すること。現状のページは未接続・未公開であり、旧名のまま本番投入しない。

## 実装・検証ゲート
- 管理者投稿フォームで公開範囲3択・返信設定2択を選べる
- 公開後に範囲変更したときキャッシュと検索インデックスを無効化する
- 無料会員の閲覧と有料会員の閲覧/返信を別ユーザーでテスト
- 未ログインの匿名RESTアクセス、SSR、ブラウザ、直接URLで非公開情報が取得できないこと
- 権限昇格懸念の隔離検証を終えるまで有料返信の本番公開はHOLD
- 本番データ・本番会員権限は変更しない
