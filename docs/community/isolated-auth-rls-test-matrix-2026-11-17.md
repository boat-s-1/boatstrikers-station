# 会員プロフィールの隔離テスト・マトリクス（実行前レビュー）

## 前提
- 本番データと本番アカウントを使用しない。
- 検証用の独立したユーザーA/B、検証用の運営アカウント、隔離DBを用意する。
- 本番キー、実ユーザーのメールアドレス、トークンをログに出さない。
- 課金Webhook、LINE連携、既存マイページへの影響を必ず調べる。
- 隔離ブランチは時間課金の承認を受けてから作成し、完了後に削除する。

| ID | 操作 | 期待結果 |
| --- | --- | --- |
| P01 | 未認証でプロフィールSELECT | 拒否 |
| P02 | ユーザーAが自分の表示名UPDATE | 成功（許可する場合のみ） |
| P03 | ユーザーAが他人Bの表示名UPDATE | 拒否または0件 |
| P04 | ユーザーAが自分の is_admin=true | 拒否 |
| P05 | ユーザーAが自分の plan='premium' | 拒否 |
| P06 | ユーザーAが自分の membership_status を変更 | 拒否 |
| P07 | ユーザーAが自分の premium_until を延長 | 拒否 |
| P08 | ユーザーAが自分の beta_member=true | 拒否 |
| P09 | ユーザーAが user_id をBに変更 | 拒否 |
| P10 | ユーザーAが特権列を含むINSERT | 拒否 |
| P11 | 正規のサーバー処理による課金状態UPDATE | 成功 |
| P12 | 正規の管理者処理による is_admin 更新 | 許可された操作のみ成功 |
| P13 | 課金期限切れで有料スレッド閲覧 | 拒否 |
| P14 | 無料会員でmembersスレッド閲覧 | 成功 |
| P15 | 未認証でmembersスレッド閲覧 | 拒否 |
| P16 | 無料会員でpublicスレッドへ返信 | 拒否 |
| P17 | 有効な有料会員で返信許可スレッドへ返信 | 成功 |
| P18 | 有料会員でもlocked/disabledスレッドへ返信 | 拒否 |
| P19 | 管理者以外による公式投稿作成 | 拒否 |
| P20 | 非公開スレッドのOG/RSS/sitemap/キャッシュ漏えい | なし |

## 実施順序
1. DBの依存関係と既存編集APIの全経路を確認
2. 隔離DBで修正前の権限を実APIで再現
3. テーブル単位/列単位の実効権限を制限
4. P01〜P12の認証・既存機能回帰試験
5. 掲示板テーブルとRLSを隔離DBへ追加
6. P13〜P20の閲覧・返信・公式投稿試験
7. ロールバック可能性・コスト・ログ・差分を報告
8. 本番変更は別途明示承認を受けるまでHOLD

この文書は検証計画のみ。テストユーザー作成、ブランチ作成、DB書き込みは行っていない。
