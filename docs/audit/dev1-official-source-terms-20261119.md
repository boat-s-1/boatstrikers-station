# 開発① 公式データ取得元の利用条件確認

更新: 2026-11-19 JST。一次資料: https://www.boatrace.jp/owsp/sp/extra/policy.html 、https://www.boatrace.jp/owpc/pc/extra/data/download.html 、https://www1.mbrace.or.jp/od2/B/dindex.html 。

公式サイトは全国24場の番組表ダウンロードを引き続き案内している。2025-03-05に終了したのは「番組表閲覧」「オッズ情報・結果」「競走成績閲覧」であり、番組表ダウンロードそのものが終了したとは書いていない。既存の docs/trinity/official-previous-day-capture.md も同じ候補を記録しており、この資料を再利用する。ファイル本体・形式・公開時刻・全場網羅・クラウドからの到達性は未検証。

公式サイトポリシーは、サイト上のコンテンツの無許諾利用（法令や個別条件の例外を除く）と、運営を妨げる大量アクセスを制限している。ダウンロードが公開されていること自体は、BoatStrikersでの継続的な取得・保存・再配信・商用表示の許可を意味しない。公式は情報が常に最新とは限らないとも明記。診断の少数GETと、本番の継続取得・サイト掲載は分けて判断する。

次の確認対象: (1) 番組表ファイルの提供主体と具体的な保存・加工・掲載許諾、(2) 一日一括取得の許容時刻・頻度、(3) 直前情報の各項目と必要取得頻度・許諾、(4) 候補OpenAPIの元データ利用条件。確認が取れるまで新規の定期取得や商用掲載を有効化しない。既存のWindowsは停止したまま。本番DB/Cron/Vercelを変更しない。
