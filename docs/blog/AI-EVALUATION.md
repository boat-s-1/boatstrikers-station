# AI記事の評価表（PHASE 5.2）

AI下書きを、自動の採点だけでなく、人の評価と編集者の修正箇所もあわせて比べるための表です。

- 承認できるかどうかは、これまでどおり「要修正」（blocking）だけで決まります。この表の点数で承認・公開が決まることはありません。
- DBには保存しません。自動の値は、ステージングの下書きを読み取り専用で写した固定データ（`tests/blog/_tokonameV*.mjs`、`_todaV10.mjs`、`_todaV11.mjs`、`_v12Staging.mjs`、`_v13Staging.mjs`）からローカルで計算します。
- 戸田v11の固定データ（`tests/blog/fixtures/toda-v11-staging-20261012.json`）は、ステージングの記事・ブロック・元データ・作成時の確認結果をそのまま写したものです。ステージングの `md5(jsonb::text)` と一致することをテストで確認しています（v10の元データからの再構成ではありません）。
- **自動の評価**（採点表）と、**記事を読んだ編集評価**は分けて記録します。下の「人の評価」は人が記入する欄で、まだ記入されていません。

## 使い方

1. 記事を固定データにしたら、`scripts/blog/ai-evaluation.mjs` の `ARTICLES` に追加します。
2. `node scripts/blog/ai-evaluation.mjs` を実行し、出力された表で下の「自動の評価」を置き換えます（テストで一致を確認しています）。
3. 「人の評価」と「編集者の修正」は、記事を読んだ人が手で記入します。空欄は未評価です。
