# BoatStrikers NEWS 既知の課題

## 女子ニュースの分類漏れ（2026-10-12 記録）

`/news?category=women`（女子タブ）と初音の担当判定は `lib/newsTaxonomy.js` の `isWomenNews()` を共通で使う。

判定条件:

- `category = 'women'` の記事は必ず対象
- 見出しに「女子・ヴィーナス・レディース・クイーンズ・プリンセス」を含む
- 要約・本文に同じ語を含む。ただし収集時に付いた定型文（「女子ボートレース関連ニュースです」「女子戦をチェックするうえで…」など）は判定から除外する

定型文は男子選手の記事にも付いているため除外が必要だが、その結果、本文が定型文だけで見出しに上記の語がない女子選手の記事が漏れる。

本番データでの検証（読み取りのみ）:

- 定型文を含む公開記事 550 件のうち、女子と判定できたのは 183 件
- 判定できなかった 367 件のうち新しい 60 件を目視すると、約 20 件が女子選手の記事と見られる（例: 魚谷香織、田口節子、安井瑞紀）

選手名から性別を推測することはしない方針。`bs_racers.gender` は全件空（1,447 件）のため現状は使えない。
この列に値が入れば、DB 変更なしで「見出しに含まれる女子選手名」による判定を追加できる。

今回は DB 変更・データ補充を行わない。
