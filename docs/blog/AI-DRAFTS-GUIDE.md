# AI下書き 操作ガイド（管理画面・初心者向け）

この画面では、AI が記事の下書きを作ります。**公開は必ず人が確認・承認してから**です。AI が勝手に公開することはありません。

## 0. はじめに：ログインと画面の場所
1. 管理画面にログインします（いつもの管理者パスワード）。
2. 「BLOG 記事管理」（`/admin/blog`）を開き、右上の「**AI下書き**」ボタンを押します。
   - 「AI下書き機能は無効です」と表示される場合は、まだ機能が有効になっていません。閲覧だけできます。

## 1. テーマを選ぶ
1. 「1. テーマを選ぶ」で、**カテゴリー**を選びます（24場の基本・24場攻略・24場の魅力・BoatStrikers DATA LAB・キャラクター）。
2. カテゴリーによっては「**場**」も選びます（例：桐生）。
3. 「未登録のテーマ候補」から使いたいものの「**テーマに登録**」を押します。
   - すでに登録したテーマや、同じテーマは候補に出ません（重複防止）。

## 2. 公式情報を確認・取得する（特に「24場の魅力」「キャラクター」）
1. 「2. 公式情報」で、対象の場になっていることを確認します。
2. BOAT RACE 公式の場データは、最初から対象です。
3. **場の公式サイトのページ**（施設・グルメ・歴史など）を使いたいときは、次を入れて「**URLを登録**」を押します。
   - URL（https で始まるもの）
   - 出典名（例：「BOAT RACE桐生 公式サイト グルメ」）
   - 種類（場の公式サイト）
   - 登録者名
4. 「**公式情報を取得**」を押すと、ページの内容を取り込みます。
   - 「取得履歴」に、取得日時と「取得済み／失敗」が表示されます。
   - 失敗した場合は理由が表示されます。例：「本文をほとんど取得できませんでした」は、画像中心のページです。文章が載っている別のページの URL を登録してください。

## 3. AI で下書きを作る
1. 「下書き作成を待っているテーマ」の「**AIで下書きを作成**」を押します（1〜3分かかります）。
2. 終わると「下書きを作成しました（要修正 ○件・確認 ○件）」と出ます。「**記事編集で確認する**」を押します。
   - 公式情報が足りないときは、作成前に止まります。手順2で URL を登録・取得してから、もう一度押してください。
   - 似た記事がすでにあるときも、作成前に止まります。

## 4. 下書きを確認する（記事編集画面）
画面の上に「**AI下書きの確認**」が表示されます。
1. **確認結果**を読みます。
   - 赤い「**要修正**」：直さないと承認できません。例：出典にない数値、出典が付いていない数値、使ってはいけない表現（「絶対」など）。
   - 黄色い「**確認**」：人の目で確かめてほしい点です。例：取得日時の記録がない収録データ、AI が「要確認」とした点。
2. 「**出典と取得日時**」を開いて、どの情報をもとにしたかを確認します。
3. 本文は、いつもの編集画面（「本文ブロック」タブ）で直せます。
4. 「**プレビュー**」で、公開時の見た目を確認します。

### 自分で事実（数値など）を書き足した場合
1. 書き足した段落の「出典URL」欄に、確認したページの URL を入れます。
2. 「AI下書きの確認」の「**人が追記した事実の出典を登録する**」を開き、次を入れて「**出典を登録**」を押します。
   - 追記した事実
   - 出典名
   - 出典URL（手順1と同じ URL）
   - 確認した日時
   - 登録者名
3. 記事の出典欄に、確認日時付きで自動追加されます。

### 表紙画像を変えたい場合
1. 「表紙とSNS・note原稿」の「**表紙画像を作り直す**」で、キャラクターとポーズを選びます。
2. 「表紙を作り直す」を押します。現在のタイトルで、表紙と SNS 用の画像が作り直されます。

## 5. 承認する
1. 「要修正」が0件になったら、「承認者名」に自分の名前を入れて「**この版を承認する**」を押します。
2. 「承認済み（この版）」と表示されれば完了です。承認者名・ログイン情報・日時・版が記録されます。

**承認したあとに本文・出典・表紙を変えると、承認は外れます。** もう一度確認して承認してください。

## 6. 公開する
1. 「公開設定」タブで、「**編集版を公開する**」または日時を指定して「**予約**」を押します。
2. 承認されていない AI 下書きは、ボタンが押せません。

## 7. note・X・YouTube の原稿を作る（任意）
1. **承認済み**または**公開済み**の記事で、「表紙とSNS・note原稿」の「**note・X・YouTube向けの原稿を作る**」を開きます。
2. 作る媒体にチェックを入れ、作成者名を入れて「**原稿を作る**」を押します。
3. 各原稿の確認結果を見て、「確認OK」のものは「**コピー**」して各サービスに貼り付けます（自動投稿はしません）。
   - 記事にない数値などが含まれると「要修正」となり、コピーできません。
   - X の投稿は、記事を公開してから行ってください。

## 8. 定時の自動作成（現在は無効）
- 「4. 定時の自動作成」に「無効」と表示されていれば、自動では何も作りません。
- 有効にすると、決まった時刻に、登録済みのテーマから下書きを自動で作ります。
  - **公開はしません。** 作られた下書きは、手順4〜6で確認・承認・公開します。
  - 作成の履歴（成功・失敗）は、同じ欄に表示されます。

## 困ったとき
| 表示 | 対処 |
|---|---|
| 「保存できていない変更があります」 | 下の「保存」を押してから、もう一度操作してください |
| 「最新版と競合しています」 | 画面を再読み込みしてください（入力内容は端末に控えがあります） |
| 「公式情報を取得できていません」 | 手順2で URL を登録して「公式情報を取得」を押してください |
| 「出典URLが登録されていません」 | 手順4の「人が追記した事実の出典を登録する」で登録してください |
